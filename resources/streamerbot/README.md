# Шаблон Streamer.bot для Тапёра

`tapyor-template.txt` — готовая строка импорта для Streamer.bot 1.0.7: группа действий «Тапёр», триггеры
«Тапёр → …», настройки и тексты ответов. Версия 1.0.0 (внутри Streamer.bot — действие «Тапёр: шаблон v1»).
Тапёр копирует эту строку кнопкой «Скопировать шаблон».

**Строку не генерируем** — её делает сам Streamer.bot через Export: вручную собранные действия, C#, триггеры
и значения по умолчанию. `src/` — те же C#-исходники и заметки для сопровождения; в программу они не
встраиваются и в установщик не входят.

Как обновить шаблон: собрать или поправить действия в Streamer.bot → Export группы «Тапёр» с именем
«Тапёр — заказы из чата», автором «Тапёр» и новой версией → положить полученную строку сюда байт в байт
(одной строкой, без перевода строки в конце) → обновить `*.cs`, `BUILD.md` и `CHECK.md` в `src/`.
Проверка — импорт строки в чистый Streamer.bot; ключей, паролей и ников в ней быть не должно.
