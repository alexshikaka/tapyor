# Оверлей-плейлист для OBS — справка для правок

> Модуль пака стримера (как чат-бот). Код модуля — в **`alexshikaka/tapyor-modules`** → `streamer-pack/overlay/`.
> В установщик Тапёра пак не входит: он ставится из программы отдельным подписанным файлом.
> Лицензия — общая с ботом (пак стримера, с 0.32.0 настоящая): условия — в `alexshikaka/tapyor-modules`. Страницы оверлея ядро отдаёт со строгим CSP (TAP-15): встроенные скрипты и стили не работают — только файлы пака.
> Макет, по которому сделано, — холст Claude Design «Тапёр · Оверлей-плейлист» (03.11.2026).

## Что это

Страница `http://127.0.0.1:47654/overlay/playlist` — источник «Браузер» в OBS, 1920×1080, прозрачная.
Стиль «DOS-терминал»: обложка (пикселизованная, нет обложки — пластинка), TRACK/ARTIST, вертушка и время,
осциллограмма, прогресс из 32 ячеек, список «дальше» 0–10 строк с затуханием.
Настройки — «Настройки → Модули → Оверлей-плейлист», там же живое превью.

| Мост ядра для модулей: страницы на сервере, плеер, `mod-cmd`, пульт с телефона (`core.remote`) | `src/modhost.js` (`http`, `playerFor`, `mod-cmd`, `mod-player`, `mod-level`, `core.remote`), `src/main/remote-bridge.js` | да |
| Сервер: префиксы модулей (только GET), обложка своего файла | `src/main.js` → `modMounts`, `modhost.setup({ mount, unmount, pageUrl, localCover })` | да |
| Снимок плеера и уровень звука из окна | `src/ui/25-overlay.js` → `ovSnap`, `ovFeed`, `ovLevels`; уровень — `vizOvLevel` в `src/ui/17-viz.js` | да |

## Как идут данные

```
окно Тапёра ──(mod-player: снимок, только когда модуль просит)──► modhost ──► модуль overlay ──(SSE)──► страница в OBS
            ──(mod-level: уровень 0…1, ~11/с, только «Настоящий звук»)──┘                         ▲
модуль ──(core.player.want({state, levels}))──► modhost ──(mod-player-want)──► окно             превью в настройках (?preview=1)
```

- **Никто не смотрит — ничего не шлём.** Модуль просит данные, только пока подключена страница (OBS или превью).
- Снимок уходит при смене трека, паузе, изменении списка и перемотке (уход > 1,5 с от ожидаемого);
  секунды страница досчитывает сама. Раз в 15 с — повтор на всякий случай.
- **Настоящий звук:** тот же захват звука окна, что у визуализатора (`vizCapture`), но держится и при
  свёрнутом окне, пока оверлей просит уровни и трек играет. Окно шлёт одно число — общую громкость:
  осциллограмма — бегущая лента, ей больше не нужно. Тишина > 3 с при игре или нет захвата
  (запасной путь через сайт Яндекса) — страница сама переходит на имитацию.
- **Превью** — iframe той же страницы (`?preview=1`, не считается источником OBS; `&demo=1` — демо-трек,
  `&paused=1` — пауза). Подключается, только пока раздел виден; экран превью прилипает к верху при прокрутке.

## Безопасность

- Страница модуля **только читает**: сервер пускает к префиксу модуля только `GET`/`HEAD`, команд у неё нет.
- Модуль отдаёт только 4 своих файла (список в `PAGE_FILES`), не пути из запроса.
- Обложка своего файла (`/lcover/…` — закрыта cookie окна) отдаётся только та, что играет сейчас.
- Чужие сайты не прочитают поток: на `/overlay/events` нет CORS-заголовков, Host проверяет `localGuard`; с 11.11 ядро
  отклоняет запросы к страницам модулей с чужим `Origin`/`Sec-Fetch-Site` — сайт не займёт слоты потока (M6).
- Превью в окне — с `http://localhost:<порт>` (окно — `127.0.0.1`): другой origin, `parent.app` странице не виден (M5);
  встраивать страницу можно только в окно Тапёра (`frame-ancestors`). Тексты страница ставит только через `textContent`.

## Проверки

- Модуль: в клоне `tapyor-modules` → `npm test` (вместе с ботом).
- Ядро: `npm test`; UI-тесты `tests/ui/run.sh` (t27 знает про пункт меню «Оверлей-плейлист»).
- Страница и вкладка целиком (настоящий `modhost` + модуль + Chromium, нужен Node-пакет `playwright`):
  `node tests/overlay/page.js <папка ядра> <папка для снимков>` и `node tests/overlay/tab.js …` — их гоняет Claude в облаке.

## Известные ограничения (первая версия)

- Стиль один — «DOS-терминал»; остальные в окне показаны «позже».
- Скриншот игры для превью живёт до перезапуска окна (никуда не сохраняется — это нарочно).
- «Стримерам» вкл/выкл включает модули только после перезапуска (как у бота).
