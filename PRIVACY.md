# Какие данные Тапёр отправляет с компьютера

> Сверено с кодом 13.11.2026 (стабилизация: аудит P5b и задание B10 — каждое сетевое направление в коде есть здесь, и наоборот).
> Правило проекта: добавили новый запрос в сеть — в том же коммите правим эту страницу.

Коротко: **Тапёр работает на твоём компьютере.** Входы в сервисы (Яндекс, YouTube, Twitch, донаты) хранятся только
у тебя, зашифрованными средствами Windows (если хранилище ключей Windows доступно; иначе — см. оговорку в §6).
Автору Тапёра они не отправляются. Рекламы, счётчиков посещений и продажи данных нет.

Любой сайт, к которому обращается программа, видит твой IP-адрес — так устроен интернет. Ниже — что ещё и куда уходит.

## 1. Сервисы, в которые ты входишь сам

Тапёр обращается к ним напрямую, от твоего имени, как браузер:

| Куда | Зачем |
|---|---|
| Яндекс Музыка (`music.yandex.ru`, `api.music.yandex.net`, вход — `oauth.yandex.ru`, `passport.yandex.ru`; имя и аватарка — `login.yandex.ru`, `avatars.yandex.net`) | поиск и музыка из твоего аккаунта |
| YouTube / Google (`youtube.com`, `googleapis.com`, вход — `accounts.google.com`) | поиск и видео |
| SoundCloud, Audius | поиск и музыка |
| Twitch (`id.twitch.tv`, `api.twitch.tv`) — только с паком стримера | чат-бот, награды за баллы |
| DonationAlerts, DonatePay | получать донаты с заказами |
| GitHub — только если ты включил свою страницу стримера | выложить твою страницу в **твой** репозиторий |

## 2. Облачные функции Тапёра (Яндекс Облако)

У Тапёра есть несколько маленьких функций в Яндекс Облаке. Через них проходит:

| Что | Что уходит | Хранится ли |
|---|---|---|
| **Вход в DonationAlerts и Google** | одноразовый код входа → функция меняет его на токен (там лежит секрет приложения, который нельзя класть в установщик) | нет: токен возвращается тебе и не записывается |
| **Лицензии пака стримера** | 3 хэша компьютера (не серийники — из хэша их не восстановить), ключ покупки при активации, название пака | хэш ключа и хэши компьютера — да, чтобы ключ работал на ≤ 3 компьютерах и пробный период был один. Самого ключа на сервере нет |
| **Время сервера** | пустой запрос при запуске, если установлен пак | нет. Нужен, чтобы перевод часов назад не продлевал пробный период |
| **Защита от перебора** | IP-адрес запроса | до 2 часов, потом удаляется сам |
| **Отчёты об ошибках** — см. п. 3 | | |

## 3. Отчёты об ошибках (можно выключить)

Когда что-то перестаёт работать (сервис не отвечает, вход устарел), Тапёр отправляет короткий отчёт, чтобы автор
узнал о поломке раньше, чем ты напишешь. Один и тот же сбой — не чаще раза в сутки.

**Что в отчёте:** какой сервис и на каком шаге сломался, текст ошибки (из него вырезаются пути к папкам, почта,
токены и длинные ключи), версия Тапёра и Windows, сборка (`build`), коммит (`commit`), версия рецептов сайтов,
случайный номер установки (не связан с тобой — чтобы считать, у скольких людей одна и та же ошибка).

**Чего нет:** ников, заказов, названий твоих файлов, входов в сервисы.

**Куда:** задача в закрытом репозитории автора на GitHub.
**Выключить / посмотреть, что уходит:** Настройки → «Отчёты об ошибках» → «Что отправляется».

## 3a. Файлы для проверки (отладочное меню)

В строке поиска можно ввести `tapyor debug` — откроется отладочное меню. В нём есть «Сохранить журнал»
и «Собрать отчёт». Оба файла **сохраняешь ты сам** через обычное окно «Сохранить как»; программа
никуда их не отправляет и не делает для этого ни одного запроса в сеть.

**Что попадает в отчёт:** состояние программы (версия, сборка, коммит, канал обновлений, словами —
состояние лицензии пака, версия пака, запущены ли модули, есть ли входы в сервисы — только «есть / нет»,
число автопочинок за сессию), настройки **без ключей** и весь журнал работы. Путь папки пользователя
сокращается: `C:\Users\<имя>` → `C:\Users\…`.

**Что не попадает:** ключи и токены лицензий (`modSecure*`, `modLicenseKey`, `modLicenses`), cookies и
ключи входов, пароли, поля с именами вроде token/key/secret/cookie/auth. Перед записью весь текст
дополнительно проверяется шаблонами секретов (`src/secret-patterns.js`), совпадения заменяются на
`[скрыто]`. Ники зрителей и тексты заказов остаются **как есть** — без них отчёт бесполезен.

«Сохранить журнал» кладёт в один файл весь `log.txt` и прошлый `log.txt.1` (если есть). «Подробный
журнал на эту сессию» — переключатель: он пишет больше строк о поиске, потоке, заказах и донатах, но
только в памяти и только пока Тапёр запущен; после перезапуска выключается сам.

Файл никуда не уходит сам. Если ты отправишь его автору или в чат — это твоё действие.

## 4. Справочники и вспомогательные запросы

| Куда | Что уходит | Зачем | Выключить |
|---|---|---|---|
| Deezer, iTunes, MusicBrainz, Last.fm | текст заказа (исполнитель — название) | узнать точное название песни | галочка «Внешние справочники» |
| Spotify (`open.spotify.com`), Apple Music (`music.apple.com`) — только когда ты сам вставил ссылку в «Импорт по ссылке» | адрес вставленной ссылки (на плейлист/альбом) | разобрать список песен из ссылки | не вставлять ссылку |
| Telegram (`t.me/s/<канал>`) — только когда ты сам вставил ссылку на открытый канал | имя канала из вставленной ссылки | прочитать открытые посты канала и собрать из них песни | не вставлять ссылку |
| Google (`suggestqueries.google.com`) | то, что ты печатаешь в строке поиска | подсказки при наборе | нельзя (как в браузере с подсказками) |
| ЦБ РФ (`cbr-xml-daily.ru`), `open.er-api.com` | ничего, только скачивается курс | донат в другой валюте → в твою валюту | — |
| RIPE (`stat.ripe.net`) | номер сети Яндекса (публичный) | раздел «VPN и Яндекс»: список адресов Яндекса | — |
| The Color API | цвет (например `#8B7CF6`) | палитры в «Оформлении» | не нажимать «подобрать палитру» |
| `ya.ru`, `google.com/generate_204` | ничего | «Быстрая проверка»: есть ли интернет | — |
| `youtube.com/generate_204`, `soundcloud.com`, `api.audius.co`, `api.deezer.com`, `api.music.yandex.net/genres` | ничего (служебный запрос без данных) | «Быстрая проверка»: доступна ли площадка | — |

**Last.fm из России** сейчас отвечает отказом на запросы с российских адресов (проверено и с серверов, и с обычных
подключений), поэтому у пользователей в России он обычно работает **только через VPN**. На остальную программу это
не влияет: без Last.fm просто не будет части сведений об исполнителе.

## 4a. Страница стримера и QR-код

Страницу стримера и QR-код для OBS Тапёр собирает **сам** и выкладывает в твой репозиторий GitHub. В готовых
файлах нет ни одного `<script>`, ни счётчиков, ни внешних библиотек: QR-код — обычная картинка, нарисованная
внутри страницы. Поэтому те, кто открывает твою страницу или QR, не обращаются ни к чьим серверам, кроме GitHub,
где лежит сама страница. Подробности о единственной сторонней библиотеке — в `THIRD-PARTY.md`.

## 5. Обновления

| Куда | Зачем |
|---|---|
| GitHub (`github.com/alexshikaka/tapyor`, отладочный канал — `tapyor-releases`) | проверить и скачать новую версию Тапёра, проверить подпись установщика |
| GitHub Pages (`alexshikaka.github.io/tapyor-web/packs.json`) | список версий пака стримера |
| GitHub (`raw.githubusercontent.com/alexshikaka/tapyor-web/main/recipes.json`) | свежие «рецепты» сайтов (селекторы), чтобы починка сайта приезжала без новой версии. Скачивается только этот файл, ничего о тебе не уходит |
| GitHub (`yt-dlp/yt-dlp`) | новая версия загрузчика YouTube |

Файл подписи (`<имя установщика>.sig`) скачивается из того же релиза GitHub, что и само обновление, — только когда
программа нашла новую версию. По нему Тапёр проверяет, что установщик подписан владельцем; если подписи нет,
обновление просто не предлагается. Этот запрос, как и проверка обновления, ничего о тебе не сообщает.

## 6. Что хранится только у тебя

Папка данных Тапёра (`%APPDATA%\Тапёр`): настройки, плейлисты, история, заказы, журнал работы, входы в сервисы
(зашифрованы), лицензии пака. Плюс одна запись в реестре `HKCU\Software\Tapyor` (самая поздняя дата — защита
пробного периода). Удалил Тапёр вместе с папкой данных и этой записью — ничего не осталось.

Отладочное меню (`tapyor debug`) хранит **локальные** автокопии настроек в `%APPDATA%\Тапёр\debug-backups`
(до 5 последних): они лежат только на твоём компьютере и никуда не отправляются. Тестовый профиль — временная
папка `%TEMP%\tapyor-test-…`; при следующем обычном запуске Тапёр её удаляет.

Заказы из Streamer.bot (`/sb/*`, с 0.35) пишутся в **локальный журнал** `%APPDATA%\Тапёр\sbot-journal\ГГГГ-ММ-ДД.jsonl`:
кто заказал (ник), текст заказа, что нашлось и что ответил Тапёр. Он нужен, чтобы стример мог разобраться, почему
заказ не встал; хранится 7 дней, старые файлы удаляются при запуске. Ники и тексты заказов из Streamer.bot есть
**только** в этом журнале: в `log.txt` их нет (даже в подробном режиме), в отчёте «Собрать отчёт» — тоже, а в
`orders-report.jsonl` для такого заказа пишется только длина текста (`textLen`), без самого текста. Новых запросов
в интернет порт не делает: Streamer.bot обращается к Тапёру на `127.0.0.1`, всё остаётся на этом компьютере.

Журнал чат-бота пака (`%APPDATA%\Тапёр\bot-journal\ГГГГ-ММ-ДД.jsonl`): сообщения чата Twitch, ники, тексты
заказов и ответы бота. Хранится 7 дней, старые файлы удаляются при запуске. Он нужен стримеру, чтобы разобраться,
почему заказ не встал, и никуда не отправляется.

`orders-report.jsonl` (`%APPDATA%\Тапёр\orders-report.jsonl`) — статистика заказов для отладки: время, провайдер,
id заказа, сумма и валюта, шаги разбора. Для донатов в него пишется **полный текст заказа** (он нужен, чтобы
понять, как Тапёр его разобрал); для заказов Streamer.bot — только длина текста (`textLen`), без самого текста.
Файл лежит только на твоём компьютере и никуда не отправляется.

Пульт к Streamer.bot (с 0.35) подключается только к **своему компьютеру** (`127.0.0.1`, `localhost` или `::1`) —
чужой адрес Тапёр отклоняет. Пароль пульта хранится зашифрованным в `settings.json` (safeStorage), в журнал,
отчёт и окно не отдаётся. Недоставленные события заказов лежат в `%APPDATA%\Тапёр\sbot-mailbox.json`: номер
заказа, ник, трек, номера награды и списания; обычное событие — не дольше суток, поздний ответ — не дольше двух
минут, потом удаляется. Этот файл никуда не отправляется; наружу пульт ничего не шлёт.

**Оговорка про шифрование.** «Зашифрованы» выше означает, что Тапёр просит Windows (safeStorage) зашифровать
вход. Если в системе нет доступного хранилища ключей, Тапёр сохраняет входы в закодированном виде (base64),
а это **не шифрование**: такой файл `settings.json` прочитает любой, у кого есть доступ к твоей папке данных.
Для входов донатов Тапёр пишет об этом предупреждение в журнал, для остальных — нет.
